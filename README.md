# ginzan-watch

銀山温泉の指定日に **夕食付きの空室** が出たら Discord に通知します。
GitHub Actions で10分ごとに起動し、中で1分おきにチェックします（GEOモバイル監視と同じ構成）。

## 監視している宿
| 取得元 | 宿 |
|---|---|
| 公式予約（489ban） | 瀧見舘（本館の夕食付き）・能登屋旅館・銀山荘・古勢起屋別館 |
| 楽天トラベル | 本館古勢起屋・古山閣・旅館藤屋・旅籠いとうや・旅館松本・銀山荘・古勢起屋別館・能登屋旅館 |
| じゃらん | 古山閣 新館 クラノバ |

※ 藤屋の公式サイト（tabichat）と古山閣の公式予約は対象外。藤屋・古山閣は楽天側で監視しています。

## セットアップ
1. このフォルダを GitHub の新しいリポジトリに push（Public ならActionsの時間制限なし）
2. Settings → Secrets and variables → Actions → `DISCORD_WEBHOOK_URL` に Webhook URL を登録
3. Actions タブ → ginzan-watch → Run workflow で動作確認

## 設定（watch.yml の env）
- `CHECK_IN` 宿泊日 / `ADULTS` 人数
- `DINNER_ONLY` 1=夕食付きのみ通知、0=朝食のみ・素泊まりも通知
- 宿泊日を過ぎると自動で何もしなくなります（Actions は手動で無効化してください）

## 通知のしくみ
- 新しく空いた部屋だけ通知（同じ空きを何度も通知しない）
- 一度埋まって再び空いたら、また通知
- 同じ宿の取得に10回連続で失敗したら警告を1回通知
